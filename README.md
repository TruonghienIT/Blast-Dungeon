# 🕹️ Blast-Dungeon
**Blast-Dungeon** là game hành động 2D phong cách Action Platform được phát triển bằng **Unity Engine**.  
Người chơi điều khiển nhân vật chiến đấu trong những bản đồ đầy rẫy Traps và Enemies; người chơi phải né tránh các bẫy, tiêu diệt kẻ địch và di chuyển đển cuối bản đồ để hoàn thành các màn chơi với các cấp độ khó tăng dần theo từng level màn chơi.

🛠️ Công nghệ sử dụng
| Công nghệ | Mục đích |
|---------|---------|
| Unity 2D | Engine phát triển game |
| C# | Xử lý logic gameplay |
| Tilemap & Sprite | Xây dựng bản đồ và nhân vật |
| Animator & Animation | Tạo chuyển động mượt |
| Audio System | Xử lý âm thanh & hiệu ứng |
| Unity PlayerPrefs | Lưu trạng thái game & tùy chỉnh người chơi |
| QualitySettings | Điều chỉnh chất lượng đồ họa |
